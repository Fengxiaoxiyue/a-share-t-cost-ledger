# A 股做 T 成本簿

一个免费、开源、无需安装的本地网页工具，用于记录沪深 A 股做 T 交易，并自动计算 FIFO 闭环收益、交易费用和摊薄持仓成本。

> **v1.3.0-beta.2 测试版提示：**“可移动基准”会把锚点记录及此前流水排除出当前周期累计，这一统计口径仍在验证和讨论，后续可能调整。请先导出 JSON 备份，再按需下载使用。

测试版可从 [v1.3.0-beta.2 Pre-release](https://github.com/Fengxiaoxiyue/a-share-t-cost-ledger/releases/tag/v1.3.0-beta.2) 按需下载；稳定版仍保留在 Releases 的 Latest 入口。

> 数据只保存在你的浏览器中，不会上传到服务器。本工具仅用于交易记录与计算，不构成任何投资建议；实际费用和成交结果请以券商账单为准。

## 快速开始

### 方式一：在线使用

打开 [在线版](https://fengxiaoxiyue.github.io/a-share-t-cost-ledger/) 即可使用。当前在线版跟随 `main`，本次发布后将显示 v1.3.0-beta.2 测试版标识。

### 方式二：下载到电脑使用

1. 从 [Releases 页面](https://github.com/Fengxiaoxiyue/a-share-t-cost-ledger/releases/latest) 下载最新的 `a-share-t-cost-ledger-v*.zip`。
2. 解压压缩包。
3. 双击文件夹中的 `index.html`，用 Chrome、Edge 或 Firefox 打开。

也可以点击 GitHub 页面右上角的 **Code → Download ZIP** 下载源代码；无需安装 Node.js，也不需要联网。

## 功能

- 管理多只股票及各自的初始仓位、初始成本。
- 可将任意一条买卖或股息记录完成后的状态设为当前基准，基准前历史仍完整保留。
- 记录买入、卖出、现金分红、股息红利税和备注。
- 自动计算佣金、过户费、印花税及每笔现金流。
- 支持“先买后卖”和“先卖后买”的 FIFO 自动配对。
- 展示四位小数的成交价与摊薄成本，以及持仓变化、组合仓位占比、闭环净收益、累计费用和净股息。
- 通过“股息模式”按钮随时切换净股息是否回摊至持仓成本，原始记录不会丢失。
- 生成成本、成交价、仓位和收益趋势图；成交价以橙色连续线显示，买入点为红色、卖出点为绿色。
- 导出当前股票的 CSV 明细，方便用 Excel 查看。
- 导出或恢复完整 JSON 备份。
- 从券商成交截图调用本机 Umi-OCR，按坐标解析后在可编辑校对区确认导入。
- 所有功能都在本机浏览器中运行，不依赖服务器或第三方接口。

## 第一次使用

1. 点击“添加股票”，填写股票代码、简称、初始仓位和初始持仓成本。
2. 逐笔录入买卖交易；收到现金分红或卖出后补扣红利税时，切换相应记录类型并填写金额。
3. 完成建仓后，可在对应流水行点击“设为基准”，让后续做 T 统计从该状态重新开始。
4. 在摘要、图表、FIFO 闭环表和交易流水中查看结果。
5. 如果券商费率与默认值不同，点击“费率设置”进行修改。
6. 集中录入后，从“备份与恢复”导出一份 JSON 完整备份。

浏览器会自动保存数据。清理浏览器网站数据、更换浏览器或换电脑前，请先导出备份。在线版与本地文件版的浏览器存储彼此独立，需要通过 JSON 文件迁移数据。

## 默认计算口径

- 全佣：成交额 × 万分之一，每笔不足 5 元按 5 元收取，买卖均收。
- 过户费：成交额 × 万分之 0.1，买卖均收。
- 印花税：成交额 × 万分之 5，仅卖出收取。
- 每项费用按人民币“分”四舍五入；费率可在界面中修改。
- 摊薄成本余额 = 当前基准持仓总成本 + 基准后累计买入支出（含费用）− 基准后累计卖出净收入（扣费用）。
- 当前摊薄成本 = 摊薄成本余额 ÷ 当前持仓数量。
- 移动基准时会固定保存该记录后的持仓和摊薄成本；该记录及此前流水不进入新周期的 FIFO、收益、费用和股息累计。
- 股息模式关闭时，基准后的分红与红利税仅作记录，不影响摊薄成本；开启时，分红入账降低成本余额，股息红利税增加成本余额。
- 成交价、单位成本及单位降本在页面和 CSV 中统一显示为小数点后四位；现金金额及费用按分显示。
- 组合仓位占比 = 当前股票估算持仓市值 ÷ 已添加全部股票的估算持仓总市值。估值价采用基准后的最新一笔成交价；尚无新交易时采用当前基准成本价。
- FIFO 闭环：新交易按数量依次匹配队列中最早的反向交易；支持部分成交拆分。
- 原始初始状态永久保留；当前基准可向前、向后移动或恢复，且基准持仓不放入 FIFO 交易队列。

不同券商、市场和账户的收费规则可能不同。请先按照自己的实际费率修改设置，再将计算结果与券商交割单核对。

## 数据导出

- **JSON 备份**：包含全部股票、买卖及股息流水、当前基准、费率和股息模式，可用于完整恢复。
- **CSV 明细**：包含当前股票的全部流水、基准区段和逐笔计算结果，可直接用 Excel 打开。

恢复 JSON 备份会覆盖当前浏览器中已有的数据，请先导出现有数据。

## OCR 交易与股息导入

### 首次运行

1. 在 PowerShell 中运行 `scripts\install-umi-ocr.ps1`。脚本只访问 Umi-OCR 官方 GitHub Release，自动选择最新稳定 Rapid 版、校验发布页 SHA-256，并安装到 `%LOCALAPPDATA%\Programs\Umi-OCR\`。
2. 双击 `start-local.cmd`。它会检测本机 OCR 服务；未运行时自动启动 Umi-OCR，然后以独立应用窗口打开股票工具。
3. 在网页点击“截图 OCR 导入”，确认状态显示“Umi-OCR ● 已连接”。

已安装后，日常只需双击 `start-local.cmd`。

### 导入流程

拖入一张或多张券商交易或股息截图。图片会依次发送到本机 Umi-OCR，解析结果只进入待导入区。请逐笔检查归属股票、时间、方向、价格、数量和金额；只有点击“确认导入”后，交易才会复用现有校验并保存到浏览器。

系统会提示：缺失字段、非整手数量、历史负持仓、价格乘数量与成交金额不一致、股票代码或名称不一致、低 OCR 置信度以及疑似重复记录。重复记录默认不选中；如果确认需要保留，可手工勾选。

当前支持常见的横向成交表格和纵向成交详情页，可导入买入、卖出、现金分红和股息红利税。不同券商版式可能仍需补充字段别名。

### 隐私与配置

网页只接受 `http://127.0.0.1` 或 `http://localhost` 的 OCR 地址，拒绝局域网或云端主机。启动脚本还会检查端口实际只监听本机。截图、OCR 原文和交易数据不会发送到云 OCR、分析服务或遥测系统。

默认地址为 `http://127.0.0.1:1224`。如本机必须使用其他 localhost 端口，可设置 `UMI_OCR_BASE_URL`；如 Umi-OCR 安装在其他位置，可设置 `UMI_OCR_PATH`。不要把个人绝对路径写进源码。

## 浏览器兼容性

推荐使用最新版本的 Chrome、Edge 或 Firefox。浏览器必须支持 `dialog`、`localStorage`、SVG 和文件下载功能。请勿使用无痕/隐私窗口长期保存数据。

## 开发与测试

普通用户不需要执行本节。参与开发需要安装 Node.js 20 或更高版本：

```bash
npm test
```

测试覆盖费用计算、FIFO 配对、移动与恢复基准、固定快照、清仓基准、持仓约束、组合仓位占比、OCR 解析、金额一致性、重复指纹、localhost 限制、页面元素完整性和离线资源检查。

在 Umi-OCR 已运行时，可用本地测试图片执行真实接口检查：

```bash
npm run test:ocr -- "C:\path\to\transaction-screenshot.png"
```
